## how it works

list
fleetline + UsersByRestIds, as x.com's Spacebar
listen
HLS; the stream's ID3 audio levels drive the glow
speak
WebRTC via Janus; the delayed HLS copy mutes
login
x.com's own page; only the session cookies, in Keychain
core
Rust · tokio · reqwest/rustls → UniFFI → Swift
ui
SwiftUI, with Core Animation for anything that moves
updates
Sparkle 2; EdDSA-signed appcast
dock
none // LSUIElement
telemetry
none
